# Respiratory RCT analysis code and public supplementary materials

This repository contains the statistical analysis code, de-identified analysis input files, and public non-proprietary supplementary materials used to support the manuscript:

**“AI-assisted layperson case-based respiratory assessment in China: a multicenter randomized controlled trial”**

## Public release

- **Public repository release:** https://github.com/asleepm/rct-analysis-code/releases/tag/v1.0
- **Archived citable release (Zenodo DOI):** https://doi.org/10.5281/zenodo.19647972

This repository is public at the time of manuscript resubmission.

## What this repository is for

This repository is intended to support practical verification of the reported statistical analyses and released non-proprietary supplementary materials. It is **not** a public release of the production mini-program or the full proprietary intervention stack.

Specifically, the public release supports verification of:
- the primary compliant-case GLMM analysis
- the all-randomized deterministic ITT boundary analyses
- crude descriptive analyses
- baseline, completion-time, subgroup, and figure-generation analyses

## Reproducibility boundary

The evaluated intervention in the trial was an **integrated GPT-4o/LungDiag-derived mini-program**, not GPT-4o alone. The public materials in this repository support reproducibility of the **reported statistical analyses** and public non-proprietary study documentation.

The following components are **not publicly released** in this repository because they contain proprietary implementation details and/or materials subject to data-governance restrictions:
- trial-specific WeChat mini-program source code
- exact internal prompt text
- exact chunking and reranker thresholds
- proprietary retrieval-engine configuration
- proprietary retrieval resources/settings
- the LungDiag-derived respiratory knowledge layer itself

To support independent appraisal despite these restrictions, a **minimal reproducible specification** of the evaluated intervention is provided in **Supplementary Appendix A**, including:
- architecture and workflow boundaries
- knowledge-layer provenance, scope, governance, and freeze policy
- open-source reference stack and equivalent functional components
- mock prompt frameworks preserving the task/schema envelope
- guardrail layers
- logging categories
- failure-handling principles
- deployment boundaries during the trial

## Repository structure

### `analysis/`
R scripts used to reproduce the reported analyses.

- `01_primary_compliant_case_glmm.R`  
  Reproduces the primary compliant-case GLMM analysis reported in **Table 2**.

- `02_prepare_itt_panelA_dataset_part1.R`  
  Prepares the control-arm dataset for **Supplementary Table S2 Panel A** by recoding assigned-but-unanswered items as correct.

- `03_prepare_itt_panelA_dataset_part2.R`  
  Prepares the AI-arm dataset for **Supplementary Table S2 Panel A** by recoding assigned-but-unanswered items as incorrect.

- `04_itt_panelA_glmm.R`  
  Runs the GLMM analysis for **Supplementary Table S2 Panel A**.

- `05_prepare_itt_panelB_all_correct.R`  
  Prepares the control-arm dataset for **Supplementary Table S2 Panel B** by recoding assigned-but-unanswered items as correct.

- `05b_prepare_itt_panelB_ai_all_correct.R`  
  Prepares the AI-arm dataset for **Supplementary Table S2 Panel B** by recoding assigned-but-unanswered items as correct.

- `06_itt_panelB_glmm.R`  
  Runs the GLMM analysis for **Supplementary Table S2 Panel B**.

- `07_prepare_itt_panelC_all_incorrect.R`  
  Prepares the AI-arm dataset for **Supplementary Table S2 Panel C** by recoding assigned-but-unanswered items as incorrect.

- `07b_prepare_itt_panelC_control_all_incorrect.R`  
  Prepares the control-arm dataset for **Supplementary Table S2 Panel C** by recoding assigned-but-unanswered items as incorrect.

- `08_itt_panelC_glmm.R`  
  Runs the GLMM analysis for **Supplementary Table S2 Panel C**.

- `09_crude_proportions_S1.R`  
  Reproduces **Supplementary Table S1** (crude pooled proportions and Wilson 95% confidence intervals).

- `10_time_table.R`  
  Reproduces **Table 3** (completion-time comparison).

- `11_accuracy_plot.R`  
  Generates the question-type accuracy plot corresponding to **Figure 3**.

- `12_baseline_table.R`  
  Reproduces **Table 1** (baseline characteristics).

- `13_subgroup_analysis_overview.R`  
  Reproduces the subgroup analysis overview corresponding to **Figure 4**.

### `data/`
De-identified analysis input files used by the scripts in this repository.

This includes:
- primary compliant-case analysis inputs
- recoded ITT boundary-analysis inputs
- intermediate derived Excel files generated by the deterministic recoding scripts

The deterministic ITT boundary-analysis input files are included for convenience and can also be regenerated from the corresponding preparation scripts.

- `Supplementary_Appendix_A_Trial_time_implementation_GPT4o_mini_program.pdf`
- `Supplementary_Appendix_B_Scoring_rubric_and_questionnaire_administration.pdf`

`Supplementary_Data_1_Triage_urgency_source_data.xlsx` contains the manually tabulated source counts used to construct **Supplementary Table S3**.

## Notes on interpretation

This repository should be interpreted as an **analysis reproducibility package**. It does not claim to release the full production application, the full proprietary intervention stack, or the full restricted materials used only for confidential review.

The trial evaluated the integrated mini-program as deployed during supervised questionnaire completion. Accordingly, the public code and files released here are intended to verify the reported statistical results and released non-proprietary documentation, not to recreate the commercial deployment environment in full.
