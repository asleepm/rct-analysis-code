# Respiratory RCT analysis code and supplementary materials

This repository contains the statistical analysis code and non-proprietary supplementary materials used to reproduce the reported results in the manuscript:

**“AI-assisted layperson case-based respiratory assessment in China: a multicenter randomized controlled trial”**

## Repository structure

### analysis/
Scripts used to reproduce the reported analyses.

- `01_primary_compliant_case_glmm.R`  
  Reproduces the primary compliant-case GLMM analysis reported in **Table 2**.

- `02_prepare_itt_panelA_dataset_part1.R`  
  Prepares the control-arm dataset for **Supplementary Table S2 Panel A** by recoding assigned-but-unanswered items as correct.

- `03_prepare_itt_panelA_dataset_part2.R`  
  Prepares the AI-arm dataset for **Supplementary Table S2 Panel A** by recoding assigned-but-unanswered items as incorrect.

- `04_itt_panelA_glmm.R`  
  Runs the GLMM analysis for **Supplementary Table S2 Panel A**.

- `05_prepare_itt_panelB_all_correct.R`  
  Prepares the control-arm dataset for **Supplementary Table S2 Panel B** by recoding assigned-but-unanswered items as correct.

- `05b_prepare_itt_panelB_ai_all_correct.R`  
  Prepares the AI-arm dataset for **Supplementary Table S2 Panel B** by recoding assigned-but-unanswered items as correct.

- `06_itt_panelB_glmm.R`  
  Runs the GLMM analysis for **Supplementary Table S2 Panel B**.

- `07_prepare_itt_panelC_all_incorrect.R`  
  Prepares the AI-arm dataset for **Supplementary Table S2 Panel C** by recoding assigned-but-unanswered items as incorrect.

- `07b_prepare_itt_panelC_control_all_incorrect.R`  
  Prepares the control-arm dataset for **Supplementary Table S2 Panel C** by recoding assigned-but-unanswered items as incorrect.

- `08_itt_panelC_glmm.R`  
  Runs the GLMM analysis for **Supplementary Table S2 Panel C**.

- `09_crude_proportions_S1.R`  
  Reproduces **Supplementary Table S1** (crude pooled proportions and Wilson 95% confidence intervals).

- `10_time_table.R`  
  Reproduces **Table 3** (completion-time comparison).

- `11_accuracy_plot.R`  
  Generates the question-type accuracy plot corresponding to **Figure 3**.

- `12_baseline_table.R`  
  Reproduces **Table 1** (baseline characteristics).

- `13_subgroup_analysis_overview.R`  
  Reproduces the subgroup analysis overview corresponding to **Figure 4**.

### data/
De-identified analysis input files used by the scripts in this repository.

This includes:
- primary compliant-case analysis inputs
- recoded ITT boundary-analysis inputs
- intermediate derived Excel files generated by the deterministic recoding scripts

### supplementary/
Public non-proprietary supplementary materials.

- `Supplementary_Appendix_A_Trial_time_implementation_GPT4o_mini_program.pdf`
- `Supplementary_Appendix_B_Scoring_rubric_and_questionnaire_administration.pdf`
- `Supplementary_Appendix_C_Composition_of_the_88_case_respiratory_question_bank.pdf`
- `Supplementary_Data_1_Triage_urgency_source_data.xlsx`

`Supplementary_Data_1_Triage_urgency_source_data.xlsx` contains the manually tabulated source counts used to construct **Supplementary Table S3**.

Reviewer-only supplementary materials provided with the revised submission, but not included in this public repository, include the questionnaire materials and answer keys.

### reproducibility/
- `sessionInfo.txt`  
  R session information and package versions.

### data_dictionary/
- `variable_notes.md`  
  Notes on variable structure and column indexing used across scripts.

## What is publicly provided here
This repository provides:
- statistical analysis code used to reproduce the reported results
- de-identified analysis input files used by the included scripts
- public non-proprietary supplementary materials
- documentation needed to understand script order and variable structure

## What is not further disclosed here
The following components are not further disclosed in this repository:
- trial-specific WeChat mini-program code
- internal exact prompt templates
- LungDiag-derived knowledge resource

These non-public components are described at the task and workflow level in Supplementary Appendix A.

## Reproducibility scope
This repository is intended to support practical verification of:
- the primary compliant-case GLMM analysis
- the deterministic ITT-principle boundary analyses
- the crude descriptive analyses
- the baseline, subgroup, completion-time, and figure-generation analyses

It is not intended to release the production application or the underlying proprietary knowledge resource.

## Software
- R version: 4.5.1
- Main packages used across scripts include: `readxl`, `dplyr`, `tidyr`, `lme4`, `marginaleffects`, `binom`, `flextable`, `officer`, `ggplot2`, `tableone`, `emmeans`, `forestplot`, `mice`, and `writexl`

## How to use
Please see `RUN_ORDER.md` for the recommended order of execution.
